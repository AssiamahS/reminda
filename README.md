# remindas

**Install:** open [assiamahs.github.io/reminda/install.html](https://assiamahs.github.io/reminda/install.html) in Safari on your iPhone.

Say it, it's scheduled. "Lomedico appointment 9am in Red Bank" → on-device parse (Apple Intelligence, date-detector fallback) → notification at 9, and the reminder glows green when you're near Red Bank. Tap the circle, it's done — like Reminders, minus the typing.

XcodeGen + CI (macos-26) → TestFlight on push. Watch capture target lands in v1.1.
